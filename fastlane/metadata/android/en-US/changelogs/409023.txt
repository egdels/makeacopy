MakeACopy 4.9.2
* Improved: photos from high-resolution cameras (e.g. 50 MP) use far less memory.
* Changed: a file shared into the app opens in the running app; with a document open, you add it or start a new one.
* Fixed: a possible crash when reviewing very large images.
* Fixed: changes in the options (e.g. output colour) sometimes only took effect after opening the options a second time.
