# Synthetic layout pages

Generated by `tools/synth-pages/gen_issue87_pages.py` from own text with the Liberation
fonts. They mimic the geometry of the pages attached to GitHub issue #87 (three justified
columns with line numbers, a two-column article with a drop cap and a footer, a bold
headline over three columns, huge digits over small captions) without their copyrighted
content.

Each `<name>.png` comes with `<name>.gt.txt`: the drawn text lines, one per line, in
drawing order (column by column). `SyntheticPageRegressionTest` runs the pages through
the Paddle pipeline and checks that every reference line is present in the OCR text
(whitespace-insensitive, fuzzy) and reports how many lines came through intact.

`<name>.reference.json`, where present, is the output of the reference PaddleOCR
pipeline (paddle-worker, same detector/recogniser model pair as the app) for the same
image, produced by `tools/synth-pages/reference_ocr.py`. The test uses it as an oracle:
the app must not lose more reference lines than the reference pipeline does.

Regenerate after changing the generator:

    python3 tools/synth-pages/gen_issue87_pages.py app/src/androidTestPaddle/assets/synth
