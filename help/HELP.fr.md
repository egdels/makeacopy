# Aide

MakeACopy transforme le papier en PDF consultables, entièrement sur votre
téléphone. Une numérisation passe par quatre écrans : Appareil photo,
Recadrer, OCR et Exporter. Tout ce qui se règle se trouve sous
**Options**, le bouton à curseurs de l'écran de l'appareil photo.

## Prendre une photo

- Tenez le téléphone au-dessus de la page de façon à voir les quatre
  coins. Touchez l'aperçu pour faire la mise au point.
- Touchez **Scanner** pour prendre la photo. La lampe aide quand la
  lumière est faible, le bouton de zoom rapproche les petites pages.
- **Charger** prend à la place une image ou un PDF déjà présent sur le
  téléphone. Vous pouvez aussi partager des images et des PDF vers
  MakeACopy depuis d'autres applications, ou les ouvrir avec MakeACopy.

## Recadrer

- MakeACopy trouve lui-même les bords de la page. Faites glisser les
  coins ou les bords là où ils sont décalés ; le bouton d'alignement
  aligne les coins sur des angles droits.
- Les boutons de rotation tournent la page par pas de 90°, le bouton de
  format d'image fixe un format de page.
- Pour les pages de livre qui se courbent vers la reliure, activez les
  bords courbés et faites glisser les points centraux des bords supérieur
  et inférieur sur le bord courbé de la page.
- Touchez **Recadrer** pour continuer.

## Reconnaître le texte

- L'écran OCR reconnaît le texte tout de suite. Choisissez d'abord la
  **Langue** du document si une autre est affichée. Les langues sont
  regroupées par écriture : le français, l'allemand, l'espagnol et la
  plupart des autres langues européennes se trouvent sous *Latin
  script*.
- **Vérifier** affiche les mots reconnus sur la page : touchez un mot
  pour le corriger. **Partager le texte** transmet le texte à une autre
  application.
- Touchez **Suivant** pour passer à l'export. Si vous changez ensuite de
  langue, **Traiter** apparaît pour reconnaître la page à nouveau.

## Exporter

- Choisissez **PDF** ou **JPEG**. Un PDF contient le texte reconnu, ce
  qui permet d'y rechercher et d'en copier le texte.
- **Enregistrer** place le fichier dans le dossier de votre choix,
  **Partager** le transmet à une autre application.
- Pour un document de plusieurs pages, numérisez chaque page séparément :
  chaque numérisation terminée est conservée, et **Ajouter une page**
  ajoute des numérisations terminées au document en cours. Faites glisser
  les pages dans la bande pour changer leur ordre.
- **Ajuster le recadrage** revient au recadrage de la page en cours,
  **Nouveau scan** commence le document suivant.

## Bibliothèque et collections

- Chaque numérisation terminée reste dans la bibliothèque, accessible par
  le bouton de bibliothèque des écrans Appareil photo et Exporter.
  Ouvrez-y une numérisation pour voir ses détails, la partager à nouveau
  ou l'ajouter à une collection.
- Les **Collections** regroupent des numérisations, par exemple par sujet
  ou par année.
- La durée de conservation se règle dans Options → Bibliothèque. Par
  défaut, toutes les numérisations sont conservées.

## Options

- **Numérisation** : ignorer l'étape OCR, le recadrage ou la détection
  des bords, ou afficher en direct le contour détecté de la page dans
  l'aperçu.
- **Caméra** : correction d'exposition, mise au point manuelle, et si
  l'application propose la lampe quand la lumière est faible.
- **OCR** : le mode de reconnaissance et le post-traitement qui corrige
  les erreurs de reconnaissance courantes.
- **Exporter** : format de page, qualité, couleur, la couche de texte du
  PDF, un fichier TXT séparé avec le texte, et le mode Boîte de
  réception.
- **Application** : mode accessibilité, masquage des scans dans les
  captures d'écran et les apps récentes, langue de l'application, cette
  aide et la politique de confidentialité.

## Mode Boîte de réception

Le mode Boîte de réception enregistre chaque export sans rien demander
dans un dossier fixe, par exemple un dossier que Syncthing, Nextcloud ou
SambaLite synchronise ou que paperless-ngx importe. Activez-le dans
Options → Exporter avec **Activer le dossier d'exportation par défaut**
et choisissez le dossier avec **Sélectionner un dossier**. Les noms de
fichier sont formés à partir de la date ; un fichier existant n'est
jamais écrasé.

## Mode accessibilité

Le mode accessibilité guide la prise de vue par la parole et les
vibrations, de sorte qu'une page peut être numérisée sans voir l'écran.
Les touches de volume servent alors de déclencheur. Activez-le dans
Options → Application.

## Conseils pour de bonnes numérisations

- Posez la page sur une surface sombre et unie, pour que ses bords
  ressortent.
- Une lumière venant du côté ou d'en haut évite l'ombre du téléphone sur
  la page.
- Tenez le téléphone parallèle à la page ; le recadrage redresse le
  reste.
- Pour les petits caractères, rapprochez-vous plutôt que de zoomer.

## En cas de problème

Si l'application se comporte mal, **Partager les journaux** dans
Options → Application rassemble le journal de l'application, que vous
pouvez envoyer avec une description du problème. Signalez les problèmes
sur https://github.com/egdels/makeacopy/issues.

## Confidentialité

MakeACopy n'a pas l'autorisation d'accès à Internet : vos documents ne
quittent le téléphone que si vous les enregistrez ou les partagez
vous-même. Les détails figurent dans la politique de confidentialité,
Options → Application → Politique de confidentialité.
